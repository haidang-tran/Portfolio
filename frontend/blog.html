Docker Compose Homelab

A self-hosted homelab running on a dedicated mini PC in a home network, managed entirely with Docker Compose. It provides media streaming, photo management, ad blocking, reverse proxying, and DDNS. Homelab tự host chạy trên một máy tính mini PC trong mạng nội bộ, quản lý hoàn toàn bằng Docker Compose. Cung cấp streaming media, quản lý ảnh, chặn quảng cáo, reverse proxy và DDNS.

Network Architecture Kiến trúc mạng

The network is configured to safely expose necessary services while isolating internal traffic. Mạng được cấu hình để expose các dịch vụ cần thiết một cách an toàn, đồng thời cô lập lưu lượng nội bộ.

  • Ports 80 and 443 are forwarded from the home router to the mini PC. Cổng 80 và 443 được forward từ router gia đình đến mini PC.
  • Caddy handles TLS termination and traffic routing. Caddy xử lý TLS termination và định tuyến traffic.
  • Local-only services (on .local domains) are restricted by Caddy rules to LAN subnets (192.168.0.0/24). Các dịch vụ chỉ nội bộ (trên domain .local) bị Caddy giới hạn chỉ cho phép LAN subnet (192.168.0.0/24).
  • Shared internal bridge network (homelab) handles container-to-container communication. Mạng bridge nội bộ dùng chung (homelab) xử lý giao tiếp giữa các container.

Core Services Các dịch vụ chính

1. Caddy (Reverse Proxy & TLS)

Serves as the ingress controller. Fetches Let's Encrypt certificates for public endpoints and manages local CA certificates for .local domains. Đóng vai trò ingress controller. Lấy chứng chỉ Let's Encrypt cho endpoint công khai và quản lý CA certificate nội bộ cho domain .local.

2. Immich (Photo LibraryThư viện ảnh)

High-performance photo manager utilizing face/object recognition. Trình quản lý ảnh hiệu năng cao với nhận diện khuôn mặt và đối tượng.

  • ContainersCác container: immich-server, immich-machine-learning, redis (Valkey), database (PostgreSQL + pgvector).

3. Borg Backup

Performs automated, encrypted, and deduplicated backups. Thực hiện backup tự động, mã hóa và loại trừ dữ liệu trùng lặp.

  • Database is dumped and the photo library is archived daily. Cơ sở dữ liệu được dump và thư viện ảnh được archive hàng ngày.
  • Excludes thumbnails and transcoded files to save space. Loại trừ thumbnail và file đã transcode để tiết kiệm dung lượng.
  • Pruning rules: keeps last 4 weekly and 3 monthly snapshots. Quy tắc pruning: giữ 4 snapshot hàng tuần và 3 snapshot hàng tháng gần nhất.

4. Jellyfin (Media ServerMáy chủ media)

Stream movie/audio libraries. Configured with AMD GPU hardware transcoding passthrough (/dev/dri and radeonsi VAAPI driver). Stream thư viện phim và âm nhạc. Được cấu hình với AMD GPU hardware transcoding passthrough (/dev/dri và driver VAAPI radeonsi). 

devices:
  - /dev/dri/renderD128:/dev/dri/renderD128

5. AdGuard Home (DNS & Ad BlockingChặn quảng cáo)

Restricts tracking domains and provides local split-horizon DNS routing for LAN devices. Chặn domain theo dõi và cung cấp split-horizon DNS nội bộ cho các thiết bị trong mạng LAN.

6. DDNS Updater

Polling script checking Amazon Web Services (checkip.amazonaws.com) for public IP changes and updating Namecheap DNS records accordingly. Script polling kiểm tra IP công khai qua AWS (checkip.amazonaws.com) và tự động cập nhật bản ghi DNS Namecheap khi có thay đổi.
