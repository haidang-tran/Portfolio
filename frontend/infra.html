Site Infrastructure Hạ tầng trang web

This portfolio is hosted and deployed using modern Cloud Native patterns, leveraging Infrastructure as Code (IaC) and GitOps for automated delivery. Portfolio này được host và triển khai theo các pattern Cloud Native hiện đại, tận dụng Infrastructure as Code (IaC) và GitOps để tự động hóa quá trình delivery.

Core Technologies Công nghệ nền tảng

  • Frontend StackFrontend: Built using Vite + Vanilla HTML/CSS/JS for a fast, lightweight static site. Xây dựng bằng Vite + Vanilla HTML/CSS/JS để có một trang tĩnh nhanh và nhẹ.
  • Hosting EnvironmentMôi trường hosting: Host cluster is an Oracle Cloud Infrastructure (OCI) Always-Free Kubernetes cluster (OKE). Cluster host là Oracle Cloud Infrastructure (OCI) Always-Free Kubernetes (OKE).
  • Infrastructure as Code (IaC): Configured using Terraform to declare VCN, subnets (public/private), and node pools (2x VM.Standard.A1.Flex ARM64, totaling 4 OCPUs and 24 GB RAM). Cấu hình bằng Terraform để khai báo VCN, subnet (public/private) và node pool (2x VM.Standard.A1.Flex ARM64, tổng 4 OCPU và 24 GB RAM).

Deployment & GitOps Triển khai & GitOps

  1. Bootstrap PhaseGiai đoạn khởi tạo: Terraform deploys the cluster and installs ArgoCD. Terraform deploy cluster và cài ArgoCD.
  2. App-of-Apps Pattern: ArgoCD synchronizes a master root app which deploys sub-charts: ArgoCD đồng bộ một root app chính để deploy các sub-chart:
    • Cert-Manager: Automates SSL/TLS certificates via Let's Encrypt.Tự động hóa chứng chỉ SSL/TLS qua Let's Encrypt.
    • Ingress-Nginx: Acts as the reverse proxy ingress controller.Đóng vai trò ingress controller reverse proxy.
    • portfolio-chart: Custom Helm chart for the web server deployment.Helm chart tùy chỉnh cho việc triển khai web server.

CI/CD Pipeline (GitHub Actions)

On code push to the main branch, the following automated pipeline triggers: Khi có code push lên nhánh main, pipeline tự động sau đây được kích hoạt:

  1. GitHub Actions runner logs into Docker Hub.GitHub Actions runner đăng nhập vào Docker Hub.
  2. Configures QEMU for ARM64 cross-platform builds.Cấu hình QEMU cho cross-platform builds trên ARM64.
  3. Builds the production image and tags it dynamically: ga-YYYY.MM.DD-HHMM.Build image production và gắn tag động theo format: ga-YYYY.MM.DD-HHMM.
  4. Pushes the Docker image to the registry.Push Docker image lên registry.
  5. Uses yq to update the Helm values file with the new image tag.Dùng yq cập nhật file Helm values với image tag mới.
  6. Commits and pushes changes back to GitHub.Commit và push thay đổi trở lại GitHub.
  7. ArgoCD autosync detects the commit and pulls the updated image to the cluster.ArgoCD autosync phát hiện commit và kéo image mới về cluster Kubernetes.
